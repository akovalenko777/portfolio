rwc.shtab.net

«Russian War Criminals» is a public database that allows users to search for and filter individuals implicated in war crimes against Ukraine.

The application is built using the SSR approach. Webpack was used as the bundler.

Tools & Technologies

  • Nuxt.js
  • Vue 3 / Composition API
  • Pinia
  • i18n
  • HTML5 semantic / SCSS
  • JavaScript ES6+
  • Leaflet / MarkerCluster
  • Vue Router
  • Middleware API
