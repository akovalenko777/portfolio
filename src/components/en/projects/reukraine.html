reukraine.shtab.net

«The Map of Recovery» — an interactive map of destroyed and rebuilt sites in Ukraine, designed to monitor funds allocated for reconstruction.

The application is built using the SSR principle. Vite was used as the bundler.

It features a dedicated accessibility settings panel in line with current requirements set out in the WCAG, EAA and a11y specifications.

Tools & Technologies

  • Nuxt.js
  • Vue 3 / Composition API
  • Pinia
  • i18n
  • HTML5 semantic / SCSS
  • TypeScript
  • Leaflet / MarkerCluster
  • LightGallery
  • Vue Router
  • Prozorro API integration
  • Middleware API
  • Налаштування доступності
